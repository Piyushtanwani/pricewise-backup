Design a complete, production-quality responsive web application called **PriceWise — Compare, Analyze, Shop Smarter**, an AI-powered shopping intelligence platform.

Use the attached **PriceWise Project Proposal 2.0** as the source of truth for the product's functionality and terminology.

PriceWise is NOT an e-commerce store. It is a **shopping intelligence and decision-support platform** that helps users discover products, compare products and prices across multiple stores, understand historical price trends, predict possible future prices, discover better alternatives, receive personalized recommendations, and set price-drop alerts.

The experience should feel like a combination of:

* modern product discovery platform
* price comparison engine
* financial/data analytics dashboard
* AI shopping assistant
* premium consumer SaaS product

The visual design must feel **trustworthy, intelligent, data-driven, modern, clean, premium, and easy to scan**.

Avoid making it look like Amazon, Flipkart, or a generic shopping marketplace.

---

# DESIGN DIRECTION

Create a sophisticated modern interface with:

* clean spacious layouts
* strong visual hierarchy
* rounded cards with subtle borders
* restrained shadows
* premium typography
* excellent whitespace
* clear data visualization
* intuitive filters
* compact but readable product cards
* strong price emphasis
* clear store comparison
* subtle AI visual language
* accessible contrast
* responsive behavior
* polished hover, active, loading, success and error states

Use a primarily light interface with an optional dark mode.

Suggested visual language:

Primary:
deep navy / indigo

Secondary:
cool blue / violet

Positive:
green for savings, price drops and good deals

Warning:
amber for price increases or uncertain predictions

Neutral:
white / soft gray surfaces

Do NOT overuse gradients.

Use gradients only for subtle AI-related highlights.

Typography should feel similar to Inter / Geist / SF Pro.

Use a 12-column desktop grid.

Desktop:
1440px primary design target

Tablet:
1024px

Mobile:
390px

Every screen must be responsive.

# AI UX PRINCIPLES

AI must NEVER feel like decoration.

Every AI insight should answer:

"What does this mean?"

"Why should I care?"

"What should I do?"

Examples:

GOOD TIME TO BUY

"Current price is 11% below the 90-day average."

WAIT

"Prices have historically fallen after similar discounts."

BETTER ALTERNATIVE

"This product costs ₹5,000 less and has a similar rating."

AI confidence should always be visible when appropriate.

Avoid pretending predictions are guaranteed.

Use labels such as:

High confidence
Moderate confidence
Low confidence
